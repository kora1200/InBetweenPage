# PageStudio

A clean, modern, unlisted landing page builder built with **100% Pure HTML5, CSS3, and Vanilla JavaScript**, directly connected to **Supabase**.

- **Zero TypeScript**
- **Zero React**
- **Zero build steps required**

---

## 📁 Files in This Project

```text
├── index.html     # Pure HTML layout & modals
├── style.css      # Pure CSS themes & animations
├── app.js         # Pure JavaScript logic & Supabase database calls
├── README.md      # Documentation
└── .gitignore     # Git ignore rules
```

---

## 🚀 How to Run & Host

### 1. Run Locally
Just double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox.

### 2. Host on GitHub Pages
1. Push this repository to GitHub.
2. Go to your repository **Settings** → **Pages**.
3. Under **Branch**, select `main`, folder `/ (root)`, and click **Save**.
4. Your site is now live with free SSL.

### 3. Host on Vercel or Netlify
Import your GitHub repository, leave the build settings empty (Static Site), and deploy.
